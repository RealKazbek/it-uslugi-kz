# Milestone 1 review (commit ff4212e)

Reviewer verdict: **NOT CLEAN**. There are no build or check blockers: build, check, links, hreflang, near-duplicates and HTML structure all pass. Before release, fix the content and honesty MAJORs below: the niche prices are misleading, the language switcher is wrong, the Kazakh word order is wrong, and the B2C service pages use business templates.

Scratch tools written for this review (they don't modify sources):
- `review/jaccard_exact.mjs`: an independent exact Jaccard on string 5-shingles of `<main>` text, with no hashing and no MinHash.
- `review/validate.mjs`: checks tag balance, nested `<a>`, duplicate ids, `lang`, OG tags, hreflang self/x-default, JSON-LD type, FAQ and crumb matching, prefilled TG text and WhatsApp hiding.
- `review/pagetext.mjs`: dumps a page as readable text.

## 1. Build and checks: verified

- `npm run check`: OK. Max similarity is 0.567.
- Independent exact Jaccard (`node review/jaccard_exact.mjs`) covered **62,053 pairs**. That is every pair within the same service (ru), the same service (kk), the same niche, the same city (ru, kk and niche), all hubs, plus 300 random pairs. Results: **0 pairs >0.70, 0 >0.60, 79 >0.50**, max 0.567. The top-10 list is identical to check.js, so the MinHash prefilter is not hiding anything. Statistically, P(a true 0.70 pair has est ≤ 0.5 at K=128) is about 1e-6.
  - Medians: ru 0.129, kk 0.154, niche 0.264. p99: 0.396, 0.453, 0.448.
- check.js audit. It really does check:
  - internal `<a href>` links
  - `<link>`/`<script>`/`<img>` src and href, including canonical and alternate hrefs
  - hreflang targets exist and are reciprocal
  - canonical equals the page's own URL
  - unique non-empty titles and descriptions
  - exactly one h1
  - JSON-LD parses, with no aggregateRating or review
  - orphans
  - sitemap ⇄ dist in both directions
  - robots Sitemap line and CNAME content

  Gaps (MINOR):
  - `scripts/check.js:46`: the hreflang regex depends on the attribute order `rel, hreflang, href`. If layout ever reorders the attributes, alternates silently become `[]` and the reciprocity check passes vacuously. Fix: parse each `<link>` tag and read its attributes with `attr()`. Also fail when a page with alternates lacks `x-default` or a self-reference, and when a `/kk/` service or city page has no alternates.
  - `scripts/check.js:51`: `h1s` counts `<h1` anywhere, including inside scripts. That's harmless today.
  - It doesn't check `<html lang>`, duplicate ids, nested `<a>`, OG tags, or that `wa.me` is absent while `config.whatsapp` is empty. `review/validate.mjs` does this today, and every one of these passes. Port the 15 lines into check.js.
  - The MinHash hash family `(a*h+b) mod 2^32` isn't min-wise independent. It works here empirically (it matched exact Jaccard), but a 64-bit or `mod p` prime hash would be more robust. MINOR.
