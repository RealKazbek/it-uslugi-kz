### MAJOR

1. **The service hub lead ends in a lowercase, verbless fragment on all 42 service hubs (21 ru + 21 kk).** The cause is `src/pages/hubs.js:82`:
   ```js
   <p class="lead">${esc(endDot(s.short[lang]))} ${esc(endDot(s.audience[lang]))}</p>
   ```
   `s.audience` is a dative fragment. M1 MAJOR 6 removed the "Подходит…" prefix from it, and service×city pages now render it as "Кому подходит: …", but the hub still glues it on as a separate sentence. Examples:
   - `/telegram-bot/`: "Бот в Telegram, который … отправляет вам уведомления. бизнесу, где клиенты уже пишут в Telegram…"
   - `/repetitor-programmirovaniya/`: "…для школьников с нуля. школьникам, которые хотят начать программировать…"
   - `/kk/telegram-mini-app/`: "…жазылу немесе тапсырыс. аудиториясы Telegram-да, … қажет бизнеске."

   This is the first paragraph of the 42 main service landing pages, and SPEC requires natural Russian and Kazakh. A scan for sentences that start with a lowercase letter after `.?!` finds no other page type affected.

   **Fix:** use the same label as service×city pages:
   ```js
   ${esc(endDot(s.short[lang]))} ${esc(ru ? 'Кому подходит' : 'Кімге арналған')}: ${esc(endDot(s.audience[lang]))}
   ```
   Equivalently, use `${esc(t.ui.audience)}: …`; `t` is already in scope at hubs.js:60, and `ui.audience` is 'Кому подходит' (ru.js:117) / 'Кімге арналған' (kk.js:110). Then re-run `npm run build && npm run check && node review/jaccard_exact.mjs`.
