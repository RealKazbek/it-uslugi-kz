## Key decisions

Full log: [DECISIONS.md](DECISIONS.md). Highlights:

- **Architecture:** one ESM build script; data in `src/data/` (config, services, cities, niches); sentence variants in `src/content/ru.js` / `kk.js`; one module per page type in `src/pages/`; one CSS file; no JavaScript on pages; trailing-slash URLs as `dir/index.html`.
- **URLs:** city hubs under `/goroda/{city}/` to avoid colliding with service slugs; `/sait-dlya/` index so niche hubs aren't orphaned.
- **Languages:** niche pages are Russian only (per SPEC); kk pages link to them with `lang="ru"`; kk nav items pointing to ru-only pages are marked "(орысша)"; hreflang only where both languages exist, x-default → ru.
- **Kazakh grammar:** hand-written city forms (locative/attributive: Алматыда/Алматыдағы, Оралда/Оралдағы, …); attributive before nouns; «тапсырыс беру» with dative; no suffixes generated in code.
- **Russian grammar:** precomputed case forms for service names after prepositions ("по услуге «…»").
- **Consumer services** (tutoring, PC help) use their own non-business wording and process steps.
- **Niche prices** come from the matching site service (e.g. "сайт-визитка от 35 000 ₸"), never from a cheaper unrelated service.
- **Uniqueness:** template variants chosen by hash of the page path, plus city context, sectors, region, nearby cities, niche selection and city-specific FAQ.
- **Honesty:** only SPEC facts; all prices are "от" starting prices below the Almaty market; no ratings, reviews, counts or years of experience.
- **Skipped on purpose:** `og:image` (no dependency-free PNG generation; `twitter:card summary` used) and per-page `<lastmod>` (build date used).
- **Design:** mobile-first, system fonts, receipt-style "смета" card as the signature element, sticky "Написать в Telegram" bar with prefilled text, WhatsApp button appears automatically once a number is set; dark mode; no animations.

## What you must do manually

1. **Contacts:** fill `whatsapp` (digits only, e.g. `'77001234567'`) and `phone` (e.g. `'+77001234567'`) in `src/data/config.js`, then push to `main`. The buttons appear automatically.
2. **DNS:** at the DNS provider of `realkazbek.site`, add a **CNAME record `uslugi` → `realkazbek.github.io`**. The Pages custom domain `uslugi.realkazbek.site` is already set via the API. After DNS propagates and GitHub issues the certificate, tick **Enforce HTTPS** in repo Settings → Pages.
3. **Search engines:** verify the site in **Google Search Console** and **Yandex Webmaster** (DNS TXT is simplest; for an HTML file/meta tag, add it to the build and redeploy), then submit `https://uslugi.realkazbek.site/sitemap.xml` in both.
4. **Prices:** review the starting prices in `src/data/services.js` (`priceFrom`, `unit`). Niche pages inherit their price from the matching site service.
5. **Optional:** native-speaker proofreading of the Kazakh (`src/content/kk.js` and `kk` fields in `src/data/*.js`).
6. **Optional:** add a 1200×630 `/assets/og.png` and `og:image` / `twitter:card summary_large_image` tags for nicer link previews in messengers.
