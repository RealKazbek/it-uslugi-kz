# it-uslugi-kz

Static site for **RK Dev**, the freelance IT services of Kazbek Assanbek (Almaty, Kazakhstan). It is generated by a plain Node.js ESM script (Node 20+, zero dependencies) into `dist/` and published to GitHub Pages at <https://uslugi.realkazbek.site>.

Product-catalog model in three languages: Russian (`/`), Kazakh (`/kk/`) and English (`/en/`). About 267 pages:

- products (59 x 3 languages), catalog and 8 category hubs (x 3), home, prices, portfolio, contacts (x 3);
- 25 city pages in ru and kk only (`/goroda/{city}/`);
- one trilingual `404.html`, `sitemap.xml` (with hreflang alternates), `robots.txt`, `CNAME`, `favicon.svg`.

The contract is in `SPEC-v2.md` and the top section of `DECISIONS.md`.

## Structure

```
src/build.js             build script, writes dist/
src/data/config.js       brand, contacts, usdRate, legal texts, portfolio, person
src/data/categories.js   8 categories (ru/kk/en)
src/data/products.js     aggregator of src/data/products/{category}.js
src/data/cities.js       25 cities (productFocus = 6 recommended product slugs)
src/content/{ru,kk,en}.js  UI strings and text blocks; *-process.js = 4-step process per category
src/pages/               product, catalog (+ hubs), city, static (home, prices, portfolio, contacts, 404)
src/assets/catalog.js    filter and search for the catalog (plain list without JS)
src/assets/portfolio/    optional {slug}.webp screenshots (rendered only if the file exists)
src/styles.css           single shared stylesheet
scripts/check.js         post-build checks
test/fixtures/           small data set for `npm test`
```

## Editing content

- **Add a product**: add one object to the right file in `src/data/products/` (schema in `DECISIONS.md`: slug, category, title/short/description/forWhom in ru+kk+en, `priceFrom` in KZT, `unit`, `days`, `includes`, `notIncluded`, 3 `faq`, `relatedProducts`). The product pages in all languages, the catalog, hub, prices table and sitemap pick it up; no template change is needed.
- **Prices**: change `priceFrom` of the product. On English pages the approximate USD amount is `priceFrom / usdRate`, set in `src/data/config.js` (`usdRate`, KZT per USD; rounded to 5 USD from 50 USD up).
- **Contacts**: `src/data/config.js` (`whatsapp` digits only, `phone`, `phoneDisplay`, `telegram`, `email`). WhatsApp is the primary CTA, Telegram secondary.
- **Legal text**: `config.legal` (ru/kk/en) is the only place where the words about legal status may appear; `npm run check` fails if they appear anywhere else.
- **Cities**: edit `src/data/cities.js`; use the stored Kazakh forms `kk.loc` / `kk.attr`, never build suffixes in code.
- **Portfolio screenshots**: save `src/assets/portfolio/{slug}.webp` (slug from `config.portfolio`).

## Commands

```
npm run build   # generate dist/
npm run check   # page count, links, unique titles/descriptions, near-duplicates,
                # canonical/hreflang/JSON-LD, legal words, WhatsApp link, sitemap/robots/CNAME
npm run serve   # preview dist/ locally
npm test        # build and check the fixtures (DATA_DIR=test/fixtures) in dist-test/
```

## Deploy

`.github/workflows/deploy.yml` builds, checks and deploys `dist/` to GitHub Pages on every push to `main`.

1. In the repo: Settings -> Pages -> Source = **GitHub Actions**.
2. Custom domain `uslugi.realkazbek.site` in Settings -> Pages. The build still writes `dist/CNAME` and `npm run check` verifies it.
