# it-uslugi-kz

Static SEO site for **RK Dev**, the freelance IT services of Kazbek Assanbek (Almaty, Kazakhstan). It is generated by a plain Node.js ESM script (Node 20+, zero dependencies) into `dist/` and published to GitHub Pages at <https://uslugi.realkazbek.site>. The goal is inbound orders from Google and Yandex search.

The site is in Russian (main) and Kazakh. The current build produces **2189 pages** (2188 in the sitemap):

- ru: home, service pages, service x city pages, city hubs, niche hub, niche pages, niche x city pages, prices, portfolio, contacts.
- kk: home, service pages, service x city pages, city hubs.
- `404.html`, `sitemap.xml`, `robots.txt`, `CNAME`.

Niche pages are Russian only. Run `npm run build` for the exact number.

## Structure

```
src/build.js          build script, writes dist/
src/data/config.js    brand, contacts, person, stack, portfolio
src/data/services.js  ~21 services (prices, FAQ, included items), ru + kk
src/data/cities.js    25 cities
src/data/niches.js    40 business niches
src/content/ru.js     sentence-template variants (ru)
src/content/kk.js     sentence-template variants (kk)
src/styles.css        single shared stylesheet
scripts/check.js      post-build checks
scripts/serve.js      local static server for dist/
```

## Editing content

- **Prices**: in `src/data/services.js` change `priceFrom` (KZT, shown as "from") and `unit` (`once`, `month`, `hour` or `lesson`) for a service. The value is used on every page. These are editable starting prices.
- **Contacts**: in `src/data/config.js` edit `telegram`, `email`, `whatsapp`, `phone`. While `whatsapp` and `phone` are empty (`''`), the related buttons are hidden. Fill them in (`whatsapp` digits only, e.g. `'77001234567'`; `phone` like `'+77001234567'`) and rebuild.
- **Cities and niches**: add or edit entries in `src/data/cities.js` and `src/data/niches.js`; pages are generated automatically.
- **Content templates**: sentence variants live in `src/content/ru.js` and `src/content/kk.js`; the variant for a page is picked deterministically from its slug.

## Commands

```
npm run build   # generate dist/
npm run check   # page count, broken links, unique titles/descriptions,
                # near-duplicate check, canonical/hreflang/JSON-LD, sitemap/robots/CNAME
npm run serve   # preview dist/ locally
```

## Deploy

`.github/workflows/deploy.yml` builds, checks and deploys `dist/` to GitHub Pages on every push to `main` (or manually via workflow_dispatch).

1. In the repo: Settings -> Pages -> Source = **GitHub Actions**.
2. The build writes `dist/CNAME` with `uslugi.realkazbek.site`, so the custom domain is applied automatically.

## DNS

At the DNS provider of `realkazbek.site` add a record:

| Type  | Host     | Value                 |
|-------|----------|-----------------------|
| CNAME | `uslugi` | `realkazbek.github.io` |

After GitHub issues the certificate, enable **Enforce HTTPS** in Settings -> Pages.

## SEO submission

- Google Search Console: add the property for `uslugi.realkazbek.site`, verify, and submit `https://uslugi.realkazbek.site/sitemap.xml`.
- Yandex Webmaster: add the site, verify, and submit the same sitemap.
